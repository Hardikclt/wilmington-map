# Wilmington Coastal Atlas

Interactive 3D elevation map of Wilmington, North Carolina.

Enable GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Expected URL: https://hardikclt.github.io/wilmington-map/

These are prebuilt static files. Preserve the _next folder and .nojekyll file. Terrain and imagery require an internet connection and WebGL. Sources and elevation limitations are included in the map.
